# 🍓 SmoothieTuber — Official Landing Page

Official landing page for **SmoothieTuber**: aplikasi web avatar 2D PNGTuber yang responsif dan reaktif terhadap suara secara real-time langsung dari browser tanpa instalasi software berat.

Created with love by **Anin (Ukiran Anin)** — Children's Book Illustrator & Voice Over Creator.

---

## ✨ Fitur Halaman Ini:
- **Hero & Headline Interaktif**: Menampilkan value proposition utama SmoothieTuber dan preview mockup monitor OBS / desktop.
- **Fitur Utama**: Penjelasan reaktif suara, banyak emosi (hotkeys), dan ekspor video transparan (MP4, MOV, WebM).
- **Semua Layar**: Dukungan rasio layar 9:16 (TikTok, Reels, Shorts), 16:9 (YouTube, OBS), dan 1:1 (Instagram & LinkedIn feed).
- **Cara Kerja (4 Langkah)**: Panduan ringkas dari pembayaran kode akses hingga siap siaran langsung/rekam.
- **About the Creator (Side-by-Side & Animated Avatar)**:
  - Profil dan cerita pembuatan SmoothieTuber oleh Kak Anin.
  - Kartu berlatar biru pastel SmoothieTuber (`#A9BDF0`).
  - Bingkai polaroid klasik dengan avatar yang bernapas lembut dan reaktif berbicara saat kursor diarahkan (*hover*) atau diklik.
- **Deretan Video TikTok Pilihan (Carousel 9:16)**:
  - 5 showcase video TikTok asli buatan Kak Anin yang menggunakan SmoothieTuber.
  - Carousel horizontal interaktif yang bisa digeser dengan tombol panah atau swipe.
  - Klik langsung menuju video TikTok (@ukiran_anin).
- **Call-to-Action & Footer**: Akses cepat menuju Lynk.id, panduan PDF, dan tautan sosial media.

---

## 🚀 Menjalankan Secara Lokal
Cukup buka file `index.html` di browser favoritmu, atau jalankan local web server:
```bash
python3 -m http.server 3000
```
Lalu buka `http://localhost:3000` di browsermu.
